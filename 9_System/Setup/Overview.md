# Setup – overview

Two ways to get to the identity files. Both end at the same three files in `9_System/Identity/`.

| | When | Effort |
|---|---|---|
| [[Interview prompt]] | you're starting fresh, or you want the result to be accurate | 20–30 minutes of conversation |
| [[From memories prompt]] | you've been working with an assistant for a while and have memories or an export | 5 minutes, plus rework |

The usual route is both: derive from what exists first, then close the gaps in the interview.

## Afterwards

Put the drafts into `9_System/Identity/` and **rework them once yourself**. What an assistant writes about you is a description from outside – it only becomes useful once you change the sentences that make you wince.

Deliberately leave `<open: …>` and `<assumed: …>` standing. Next time you read the file they show you where the picture still isn't right.

## When to revise

Not on a schedule, but when something prompts it: when an answer annoys you and you realise the reason is missing from one of these files. Then the file is the answer, not the next conversation.
